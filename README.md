# 🤖 AI-Powered Task Management System

An enterprise-level Data Science & ML project that automatically
classifies, prioritizes, and assigns tasks using NLP and Machine Learning.

## 📌 Project Overview
- **Domain**: NLP + Machine Learning
- **Tools**: Python, Scikit-learn, XGBoost, NLTK, Pandas, Matplotlib
- **Model**: SVM, Naive Bayes, Random Forest, XGBoost

## 📅 Week-wise Work
| Week | Work Done |
|------|-----------|
| Week 1 | Data creation, EDA, NLP Preprocessing |
| Week 2 | TF-IDF, Naive Bayes, SVM Classification |
| Week 3 | Priority Prediction, Workload Balancing, GridSearchCV |
| Week 4 | Final Dashboard, Live Prediction Demo |

## 📊 Results
| Model | Task |
|-------|------|
| SVM | Task Category Classification |
| Naive Bayes | Task Category Classification |
| Random Forest | Priority Prediction |
| XGBoost | Priority Prediction |

## 🚀 How to Run
1. Open the `.ipynb` file in Google Colab
2. Run all cells week by week
3. Final dashboard is saved as `final_dashboard.png`
